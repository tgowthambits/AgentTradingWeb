# 🔧 Issue Fixed: TypeError with indicator.name

## ❌ The Problem

```python
TypeError: unhashable type: 'dict'
```

**Location:** `indicator_manager.py` line 36
```python
self.weights[indicator.name] = indicator.weight
```

**Cause:** `indicator.name` was a dict instead of a string

---

## 🔍 Root Cause

The `BaseIndicator.__init__` had a signature mismatch:

### Before (Broken)
```python
# base_indicator.py
class BaseIndicator:
    def __init__(self, name: str, config: Dict[str, Any] = None):
        self.name = name  # ← Expected 'name' as first parameter
        self.config = config or {}

# Child indicators were calling:
super().__init__(name="RSI", config=config)
```

**Problem:** When some indicators called `super().__init__(config)` without the `name` parameter, Python assigned the `config` dict to the `name` parameter, causing `indicator.name` to be a dict.

---

## ✅ The Fix

### 1. Updated BaseIndicator

**File:** `trading_system/core/base_indicator.py`

```python
# After (Fixed)
class BaseIndicator:
    def __init__(self, config: Dict[str, Any] = None):
        """Initialize the indicator."""
        self.config = config if config is not None else {}
        
        # Auto-generate name from class name
        class_name = self.__class__.__name__
        self.name = class_name.replace('Indicator', '')
        
        self.enabled = self.config.get('enabled', True)
        self.weight = self.config.get('weight', 1.0)
```

**Changes:**
- ✅ Removed `name` parameter (no longer needed)
- ✅ Auto-generate name from class name
- ✅ `RSIIndicator` → `RSI`
- ✅ `MACDIndicator` → `MACD`
- ✅ `MACrossoverIndicator` → `MACrossover`

**Changes:**

## 📝 How It Works Now

### Creating a New Indicator

```python
class MyCustomIndicator(BaseIndicator):
    def __init__(self, config=None):
        super().__init__(config)  # ← Simple!
        # self.name is automatically "MyCustom"
        # (from "MyCustomIndicator" with "Indicator" removed)
        
        # Your parameters
        self.period = self.config.get('period', 14)
    
    def calculate(self, df):
        # Your logic
        df['signal'] = 'BUY'
        return df
    
    def get_required_columns(self):
        return ['close']
```

**Result:**
- `self.name` = `"MyCustom"` (auto-generated)
- `self.config` = provided config dict
- `self.enabled` = from config or `True`
- `self.weight` = from config or `1.0`
